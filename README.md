# steps-generator
Creado para la generación ágil de steps en la etapa de testeo para recetas con Geolocalización y otras

# listado de steps contemplados y sus variables
- wait: time
- wait field: field
- click: field / type 
- complete: field / value  
- press: key 
- press many times: key / value
- click if exists: field  
- reload page: sin argumentos  
- exec JS: code  
- goto: value 
- scroll: field / scrollIncrement
