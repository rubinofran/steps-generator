# steps-generator
Creado para la generación ágil de steps en la etapa de testeo para recetas con Geolocalización y otras

# listado de steps contemplados y sus variables
- wait: - (ver for y field)  
- click: field / type (tipos text o raro)  
- complete: field / value  
- press: key / value (ver si tiene time o no, además tipos de key como Enter y ArrowDown)  
- clickifexists: field  
- reloadPage: sin argumentos  
- execJS: code  
- goto: value (ver url o paramUrl)  
- scroll: field / scrollIncrement
